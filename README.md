# RPGRAM 1.0

Protótipo Android do RPGRAM, uma rede social de fotos com identidade própria.

## Incluído
- Feed
- Stories
- Explorar
- Nova publicação
- Notificações
- Perfil
- Navegação inferior
- Tema escuro e identidade visual RPGRAM

## Como gerar o APK
Abra o projeto no Android Studio e execute:
`./gradlew assembleDebug`

O APK será criado em:
`app/build/outputs/apk/debug/app-debug.apk`

Esta versão é um protótipo local: login, banco de dados, upload real e chat ainda precisam de backend.
